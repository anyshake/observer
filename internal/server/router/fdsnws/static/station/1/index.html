Station v1 API reference

Station metadata in StationXML or FDSN text format.

Open URL Builder Service version Application WADL

Endpoints

station v1 endpoints
Path Methods Access key Description
/fdsnws/station/1/query GET, POST Required Station metadata in StationXML or FDSN text format.
/fdsnws/station/1/version GET Public Service version
/fdsnws/station/1/application.wadl GET Public Machine-readable service description

Query requests require Authorization: Bearer <access key>. See the authentication guide and response codes.

Query parameters

station query parameters
Parameter Values and behavior
network, station, location, channel Channel selectors. Use *, ?, and comma-separated values. Use -- for an empty location code.
starttime, endtime ISO 8601 UTC times. Optional time range.
level network, station (default), channel, or response.
format xml (default) or text. level=response requires XML.
startbefore, startafter, endbefore, endafter Epoch constraints; use instead of starttime and endtime.
minlatitude, maxlatitude, minlongitude, maxlongitude Bounding box in degrees. Latitude: -90 to 90; longitude: -180 to 180.
latitude, longitude, minradius, maxradius Radius search in degrees. Both coordinates are required; radii range from 0 to 180. Use instead of a bounding box.
includerestricted true (default) or false.
nodata 204 (default) or 404 when no data matches.

Short aliases net, sta, loc, cha, start, and end are also accepted.

Instrument responses

Use level=response&format=xml to include the response metadata available for the instrument: sensitivity, poles and zeros, stage gains, and decimation. Missing metadata is omitted.

This service does not support updatedafter, matchtimeseries=true, or includeavailability=true.

Bulk POST requests

Send plain text with optional name=value lines followed by stream selections in the order NET STA LOC CHA STARTTIME ENDTIME. Each selection occupies one line. Replace the example times with an available interval.

selections.txt
level=response
format=xml
* * * * 2026-01-01T00:00:00Z 2026-01-01T00:01:00Z
cURL · Bulk request

POST bodies are limited to 1 MiB.
