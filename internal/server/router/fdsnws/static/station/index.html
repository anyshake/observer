Station URL Builder

Build a request for station metadata and available instrument responses.

Query parameters

Use * for any value, ? for one character, and commas for multiple selectors. Use -- for an empty location code.

All times are UTC. Leave time fields empty to omit the filter. Time range and epoch constraints are alternatives.

Geographic filters

Coordinates are in degrees. Radius searches require both latitude and longitude.
