Access and authentication

  1. Ask the station administrator for an access key.
  2. Choose a service above and use its URL Builder to select channels, times, and output options.
  3. Enter your access key in the URL Builder and click Send request to test it in your browser. To use cURL, set the key in your shell and copy the generated command.
Shell · Access key
export FDSN_ACCESS_KEY='<access key>'

Send Authorization: Bearer <access key> with each query request. Keys are managed by an administrator and may expire or be revoked. Keep the key out of query URLs.

Documentation, URL Builders, version endpoints, and WADL files are public while the service is enabled. Authentication is required only for station and dataselect query endpoints.

Response codes

HTTP response codes
Status Meaning
200 The request succeeded.
204 / 404 No matching data; controlled by the nodata parameter.
400 A parameter, time range, or request body is invalid.
401 The access key is missing, invalid, expired, or revoked.
404 The endpoint does not exist.
501 The FDSN service is disabled.
503 The service is temporarily unavailable.
