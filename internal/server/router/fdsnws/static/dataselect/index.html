DataSelect URL Builder

Build a request to download recorded waveform data in MiniSEED format.

Query parameters

Use * for any value, ? for one character, and commas for multiple selectors. Use -- for an empty location code.

Start and end times are required and use UTC. The default window is the last minute. The server applies its configured query duration limit.
